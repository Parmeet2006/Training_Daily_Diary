### 3. Set Mechanics & Relational Operations
* **Set Operations:** Performed set algebra using mathematical methods and bitwise operators:

  * **Difference (`-`):** Extracts elements unique to the primary set[cite: 53].
  * **Symmetric Difference (`^`):** Yields elements present in either set, but not both[cite: 53].
